# Computer Vision Task 1

This repository contains basic OpenCV setup tasks for the Computer Vision course.

## Folder Structure

- **Files/**: Contains Python scripts.
  - `images.py`: A Python script using OpenCV to load and display images.
- **Images/**: Holds sample images used in experiments.
  - Includes `/logo.png` and other sample images.

## Script Details (`images.py`)

The `images.py` script reads the `/logo.png` image located in the `Images/` folder using `cv2.imread()` and displays it in a window using `cv2.imshow()`.
